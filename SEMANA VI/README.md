En esta semana desarrollé un programa en Python usando clases, con una organización por carpetas para mantener el trabajo ordenado.

En la carpeta **modelos** definí una cuenta base y dos tipos de cuenta que se comportan diferente. Protegí el saldo para que no se cambie de forma directa, sino mediante funciones de depósito y retiro.

En la carpeta **servicios** construí la parte que administra las cuentas, permite buscarlas, hacer transferencias y aplicar cargos según el tipo de cuenta.

Para probar todo, ejecuto **main.py**. En la consola se muestra el estado inicial y el estado final, después de realizar depósitos, retiros, transferencias y el cálculo correspondiente.
