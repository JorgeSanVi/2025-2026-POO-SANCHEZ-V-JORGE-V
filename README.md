# Presupuesto semanal (Python)

En esta tarea desarrollé un programa en Python que me permite registrar mi ingreso semanal y varios gastos.  
Con la información ingresada, el programa calcula el total gastado, el saldo restante y el porcentaje gastado.  
Además, muestra una alerta si gasto el 80% o más de mi ingreso y otra observación si mi saldo queda en déficit.
